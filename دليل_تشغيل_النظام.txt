3. تشغيل النظام محلياً على جهاز الكمبيوتر

المتطلبات الأساسية:
- لغة PHP بإصدار 8.2 أو أحدث
- مدير الحزم Composer
- بيئة Node.js بإصدار 18 أو أحدث
- قاعدة بيانات PostgreSQL بإصدار 14 أو أحدث

خطوات التشغيل المحلي:

الخطوة 1: فك ضغط مجلد المشروع والدخول إليه عبر سطر الأوامر:
cd path/to/project

الخطوة 2: تثبيت حزم PHP:
composer install --no-dev

الخطوة 3: تثبيت حزم الواجهة الأمامية وبنائها:
npm install
npm run build

الخطوة 4: تجهيز ملف الإعدادات:
نسخ الملف .env.example وتسميته .env
ثم تعديل بيانات الاتصال بقاعدة البيانات بداخله.

الخطوة 5: إنشاء قاعدة البيانات واستيرادها:
إنشاء قاعدة بيانات باسم: saba_conference_db
استيراد ملف قاعدة البيانات المرفق عبر الأمر:
psql -U postgres -d saba_conference_db -f database_export.sql

أو استخدام أمر التهجير التلقائي:
php artisan migrate

الخطوة 6: تشغيل خادم النظام المحلي:
php artisan serve

الخطوة 7: فتح النظام في المتصفح عبر الرابط:
http://localhost:8000

============================================================

4. هيكل الملفات الهامة في المشروع

- مجلد app: يحتوي على كود وبرمجة النظام الخلفية (Backend PHP) ونماذج البيانات والتحكم.
- مجلد resources/js: يحتوي على واجهات المستخدم التفاعلية (Frontend React).
- مجلد database/migrations: يحتوي على ملفات بناء جداول قاعدة البيانات.
- ملف database_export.sql: ملف قاعدة البيانات الجاهز للاستيراد المباشر (يحتوي على كافة الجداول).
- ملف .env.example: نموذج لإعدادات الاتصال والبيئة.
- ملف README.txt: دليل التشغيل والإرشادات.

============================================================

5. التقنيات المستخدمة في بناء النظام

- الواجهة الأمامية (Frontend): React.js مع Vite
- الواجهة الخلفية (Backend): Laravel 11 بلغة PHP
- قاعدة البيانات (Database): PostgreSQL
- التخزين السحابي للملفات: Supabase Storage
- الاستضافة والنشر السحابي: Vercel
- نظام المصادقة والأمان: Laravel Sanctum
