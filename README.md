## 💻 تشغيل النظام محلياً على جهازك

### المتطلبات الأساسية
- PHP 8.2 أو أحدث
- Composer
- Node.js 18 أو أحدث
- PostgreSQL 14 أو أحدث

### خطوات التثبيت

**1. فك ضغط الملف المضغوط**
```bash
# استخرج الملف إلى مجلد
cd path/to/project
```

**2. تثبيت الحزم PHP**
```bash
composer install --no-dev
```

**3. تثبيت الحزم JavaScript**
```bash
npm install
npm run build
```

**4. إعداد ملف البيئة**
```bash
# انسخ ملف المثال
copy .env.example .env

# عدّل بيانات قاعدة البيانات في ملف .env
```

**5. إنشاء قاعدة البيانات**
```bash
# أنشئ قاعدة بيانات PostgreSQL جديدة
createdb saba_conference_db

# خيار أ: استيراد ملف SQL المرفق
psql -U postgres -d saba_conference_db -f database_export.sql

# خيار ب: تشغيل migrations لاريفل (إذا أردت قاعدة فارغة)
php artisan migrate
```

**6. تشغيل الخادم المحلي**
```bash
php artisan serve
```

**7. فتح النظام في المتصفح**
```
http://localhost:8000
```

## 📁 هيكل الملفات الهامة

```
├── app/                    # منطق النظام (Backend PHP)
│   ├── Http/Controllers/   # وحدات التحكم والـ API
│   └── Models/             # نماذج قاعدة البيانات
├── resources/js/           # الواجهة الأمامية (Frontend React)
│   └── Pages/              # صفحات النظام
├── database/
│   └── migrations/         # بنية قاعدة البيانات
├── database_export.sql     # ملف قاعدة البيانات للاستيراد
├── .env.example            # مثال إعدادات البيئة
└── README.md               # هذا الملف
```
